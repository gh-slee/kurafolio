Versioned quote/FX adapters, schedules/manual refresh/coalescing, rights/cadence profile, currency registry and immutable reference selection; approve providers first.

## 3. User journey and states

The affected journey and first-use/normal/empty/partial/stale/error/permission states are specified in [UX and API](../product/UX_AND_API.md). This slice implements only the bounded outcome above; skipped or unsupported states must be explained, not rendered as zero or success.

## 4. Financial invariants and examples

Directed rates and selected cutoff; no future lookup; native amounts unchanged; fresh/stale/source fallback labels distinct from holdings date.

Independent proposed cases: G07,G09,G10,G13,G18 in [golden cases](../../golden-cases.md). Expected values are fixed outside production calculations; future QA verifies independently.

Corporate-action/quantity basis G19 is mandatory where this slice uses current quotes with older quantity observations. Proposed brokerage cash, signed/unsupported instruments and funding-as-nonbalance rules are in OD-13 and the projection plan. These are explicit review choices, not hidden accounting defaults.

## 6. Security, reliability, migration and rollback

High/critical review requires Architect, independent negative/golden evidence and explicit rollback/failure plan approval. Use only synthetic isolated test data; tenant/secret/plugin constraints in [security/ops](../quality/SECURITY_OPERATIONS.md) apply.
