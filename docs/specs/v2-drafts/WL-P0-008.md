# WL-P0-008 — Project source-neutral positions and BTC Option A

## 1. Problem and user value

Existing neutral projection/frozen reports coexist with legacy opening/wallet semantics (E14,E15).

Add canonical authority selection and coherent calculation snapshot service for securities and acquisition-only BTC; retain old report read paths.

## 2. Scope, non-goals and risk

Priority P0, size MEDIUM, risk HIGH. This is an individually reviewable draft, not an implementation grant. No personal imports, migrations, remote publication or deployment are included. Shared architecture is proposed in [the overview](../architecture/OVERVIEW.md); detailed financial/security/migration choices require the linked ADR gates. Do not absorb another spec or reopen D01–D14 silently.

## 3. User journey and states

The affected journey and first-use/normal/empty/partial/stale/error/permission states are specified in [UX and API](../product/UX_AND_API.md). This slice implements only the bounded outcome above; skipped or unsupported states must be explained, not rendered as zero or success.

## 4. Financial invariants and examples

Snapshot/event non-additivity, precise known subtotal/nullable complete total, accepted unique BUY sum, transfer/funding/opening exclusion and shared Total inclusion; INV-01–10.

Independent proposed cases: G01,G02,G05,G06,G07,G08,G09 in [golden cases](../../golden-cases.md). Expected values are fixed outside production calculations; future QA verifies independently.

Corporate-action/quantity basis G19 is mandatory where this slice uses current quotes with older quantity observations. Proposed brokerage cash, signed/unsupported instruments and funding-as-nonbalance rules are in OD-13 and the projection plan. These are explicit review choices, not hidden accounting defaults.

## 6. Security, reliability, migration and rollback

Incomplete scopes/quotes return gaps. Mirrored buy ambiguity never inflated. Crash cannot publish half a generation. Revert calculation pointer/version under approved plan; canonical facts immutable.

High/critical review requires Architect, independent negative/golden evidence and explicit rollback/failure plan approval. Use only synthetic isolated test data; tenant/secret/plugin constraints in [security/ops](../quality/SECURITY_OPERATIONS.md) apply.
