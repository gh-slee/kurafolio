# WL-P0-013 — Render exports only on demand from pinned analysis

## 1. Problem and user value

Current imports publish frozen report bundles and downloads read registered bytes (E15,E21).

Download-only PDF/ODS/MD, retain useful CSV/JSON/PNG/ZIP, optional bounded private export cache keyed by calculation/scope/locale/currency/format/version.

## 2. Scope, non-goals and risk

Priority P0, size MEDIUM, risk HIGH. This is an individually reviewable draft, not an implementation grant. No personal imports, migrations, remote publication or deployment are included. Shared architecture is proposed in [the overview](../architecture/OVERVIEW.md); detailed financial/security/migration choices require the linked ADR gates. Do not absorb another spec or reopen D01–D14 silently.

## 3. User journey and states

The affected journey and first-use/normal/empty/partial/stale/error/permission states are specified in [UX and API](../product/UX_AND_API.md). This slice implements only the bounded outcome above; skipped or unsupported states must be explained, not rendered as zero or success.

## 4. Financial invariants and examples

Same exact calculation/token across rendered tables/charts/formulas; no later market fetch during export; read/export never creates source observations.

Independent proposed cases: G07,G09,G11,G16 in [golden cases](../../golden-cases.md). Expected values are fixed outside production calculations; future QA verifies independently.

## 5. Canonical contracts and architecture

Expected paths above are a scoped proposal, not a claim those new modules exist. Reuse current services from [source evidence](../EVIDENCE_INDEX.md). [Canonical model](../architecture/CANONICAL_MODEL.md), [File/API lifecycle](../architecture/DATA_SOURCE_PLUGINS.md), [projection](../architecture/PROJECTION_VALUATION.md) and [PG plan](../architecture/POSTGRESQL_MIGRATION.md) define applicable boundaries. Any contract change outside this exact slice returns for Architect/owner review.

## 6. Security, reliability, migration and rollback

Failed render/cancel cannot rollback committed facts; retry idempotent. Stage artifact then register hash/private ACL, no download until verified; clean safe orphan cache only. Revert renderer version with prior artifacts intact.

High/critical review requires Architect, independent negative/golden evidence and explicit rollback/failure plan approval. Use only synthetic isolated test data; tenant/secret/plugin constraints in [security/ops](../quality/SECURITY_OPERATIONS.md) apply.
