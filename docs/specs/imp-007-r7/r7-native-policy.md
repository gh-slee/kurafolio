exact WrapperProfile.identity_policy value from the operator-reviewed profile
selected for the member. The existing enum values are provider_scoped_stable,
snapshot_semantic and ambiguous. Do not translate them into prose, invent a source
description or add an id_policy property to the closed NativeDiscovery input.

existing evidence.id_policy text and parser_api=2.

prose and does not claim an absent field in frozen DomainBatchV1/ProvenanceV1.

the authority checks. Child output, raw/source text or the retained string alone
cannot establish stable identity. A mismatching retained native token is rejected
at new admission/preparation with import_invalid and no stage/accepted effects.
A wrong or unavailable selected profile retains the prior guard/error precedence.
