# APP-101: Add French (Canada) as a fourth interface language

## Goal

Kurafolio reads Canadian brokerage files and speaks English and two Chinese variants. French is the other official language of its first market. Add fr-CA to the V2 interface and the downloads, with Canadian French number and date formats, and keep the three existing locales unchanged.

## Context

### Background

- Japanese was the second candidate on the old list (I18N-007). It has no user request and needs a font decision for the PDF; it stays out until someone asks.
- Translated README and manual editions are a separate maintenance commitment and are not part of this ticket.

### Scope

- In scope: the fr-CA catalog for the V2 interface and exports, number, currency and date formatting, the language switcher, completeness checks, tests.
- Out of scope: translated documentation, ja-JP or other locales, the shipped SQLite application's pages, machine translation at run time.

### Implementation notes

- Stable keys and sheet identifiers do not change ([i18n-plan.md](../docs/i18n-plan.md)). A missing key fails the completeness check; it never falls back silently in the interface.
- fr-CA formats: a space as thousands separator, a comma as decimal separator, the currency symbol after the amount, dates as year-month-day in tables.
- Financial terms follow the usage of Canadian regulators and large Canadian institutions' French sites. List the chosen terms for the main concepts (book cost, unrealized gain, holdings, exposure) in the pull request for the owner to check.
- Check the PDF renderer has the glyphs; French needs no new font.
- The translation is written and reviewed in the pull request. No runtime translation service.

### Where to start

- [i18n-plan.md](../docs/i18n-plan.md); `src/kurafolio/locales/`, `src/kurafolio/i18n.py`.
- `frontend/src/v2/locale.ts`, `frontend/src/v2/language.tsx`, `frontend/src/lib/i18n.tsx`, `frontend/src/lib/format.ts`.

## Acceptance criteria

- [ ] Given fr-CA is chosen, then every V2 page and each download format is in French with no English or key names left.
- [ ] Given 1234567.89 CAD, then it is shown as "1 234 567,89 $" in fr-CA and unchanged in the other locales.
- [ ] The catalog completeness check covers fr-CA and fails on a missing key.
- [ ] The en-CA, zh-TW and zh-CN catalogs and their tests are unchanged.
- [ ] A glossary of the main financial terms is in the pull request for the owner's review.
- [ ] Screenshots for the README are refreshed only if the gallery shows a language switcher.
