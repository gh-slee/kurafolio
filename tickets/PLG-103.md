# PLG-103: Add more institutions, one reviewed file format per ticket

## Goal

Kurafolio is useful to someone only if it reads their broker's or exchange's export. It ships with two formats. Each further format is a small, repeatable piece of work once the contributor workflow exists (PLG-101). This epic holds the list of candidates and the rules every format ticket follows; each format gets its own child ticket.

## Context

### Background

- The owner named Questrade and TD as examples of institutions a user might add later (PRODUCT_CONTEXT.md, flow step 9).
- Asking users which institution they need is the best ranking. Until then the list below is a starting guess for Canadian users.

### Scope

- In scope: the candidate list, the per-format rules, one child ticket per format when the owner picks it.
- Out of scope: API connections (PLG-102), bank chequing accounts and credit cards, any format without public documentation or a legally clean sample layout.

### Implementation notes

- Candidates to rank with the owner: Questrade positions export; TD Direct Investing holdings export; Interactive Brokers activity statement (CSV); RBC Direct Investing and BMO InvestorLine holdings exports; Kraken and Coinbase transaction history (CSV). Check each institution's current export before writing a child ticket; layouts change.
- Every child ticket: one format, one plugin, synthetic fixtures made from the column layout with invented data, declared asset classes, help text in three locales, a "what this file cannot tell us" list (for example no cost, no cash), and the PLG-101 harness passing in CI.
- No change to core code for a format. If a format needs one, stop and file a contract ticket.
- The README's supported list is updated in the same pull request and never says "all banks".

### Where to start

- The contributor guide and harness from PLG-101.
- `src/kurafolio/source_builtin.py`, `examples/parser-plugin`, [source-adapters.md](../docs/source-adapters.md).

## Acceptance criteria

- [ ] The owner has ranked the candidates; the top one has a child ticket with fixtures described.
- [ ] Each merged format passes the PLG-101 harness and adds no branch on its name in core code.
- [ ] Each format's help page says which export to download from the institution and what the file does not contain.
- [ ] Re-importing the same file changes nothing; overlapping files reconcile without duplicates.

## Plan
